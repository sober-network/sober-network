🏘️ Group Hub Admin sees extra tabs
A superadmin visiting any group hub sees all tabs a group admin would — Join Requests, Settings — plus a quiet Platform overlay tab with suspend / reassign controls. No separate interface.
👤 Member Profile Admin sees extra actions
A superadmin viewing any member profile sees an elevated action bar — force-confirm email, deactivate account, assign roles — rendered inline below the profile card. Same page, elevated view.
🛡️ Platform Overview Minimal /admin
The only page with no contextual home: audit log, cost dashboard, health/uptime, platform announcements. Accessible only via the user dropdown. Quiet. Not a control room.
